# 最小版实现计划

状态（2026-10-03）：审查、性能/进展及 UI 状态修复已实现，5 套件、38 项测试通过。确认与拥有者认证合为一页，结果分类及本次会话提醒已修复。Release App、原生 UI 与完整授权的本轮验证结果以 [验证记录](validation.md) 为准；真实启动写入和两次启动仍未验收。

## 执行原则

先验证所需系统能力与授权路径，再实现扫描窗口和切换流程。不得因旧报告中的撤销缺口停掉最小版开发，也不得以未经验证的参数绕过真实问题。

收到用户实施指令后，可自主完成只读调查、开发、构建和模拟测试。真实设置启动目标、认证写入或重启须由用户安排窗口配合，普通开发测试不能触发这些操作。

- [x] 接入受限授权及一次性设置，确保所有写入路径必须具备一次性参数；不存在默认盘修改入口。

- [x] 应用仍运行时提示临时选择可能有效，不显示“已撤销”或“已完成启动”。
- [x] 为系统执行设计可替换适配边界，用模拟执行器验证分支；测试不调用真实设置或重启。

- [x] 合并确认与拥有者认证页，取消或关闭恢复可选择状态；分别呈现扫描/设置/重启结果，已有临时状态提醒不被返回、刷新或取消新操作清除。

出口：局部编译与相关测试通过，真实启动状态未被开发测试改变，尚未实机验证的部分在界面说明或交付记录中明确。

- [ ] 向用户展示本次目标及操作步骤，等待用户保存工作并安排窗口。
- [ ] 记录原默认目标及必要安全状态，确认目标连接且已就绪。

- [ ] 确认第一次进入目标系统。
- [ ] 在目标系统正常重启，不运行恢复默认盘操作，确认回到原默认系统。
- [ ] 记录默认目标核对证据、两次启动结果和安全设置保持情况。
- [ ] 有实际外置 macOS 时验收外置启动；没有设备则明确写“未验证”。

不为了测试异常分支在真实机器上主动制造启动中断、拔盘或错误配置；这些分支优先通过模拟验证。

出口：一次性切换与回到默认的实机证据完整，或明确交付为“尚未实机验收”，不将两者混淆。实测不符合要求时停止交付为可用切换工具，不通过修改默认盘补救。

## 最小测试集合

| 类别 | 场景与断言 |
| --- | --- |
| 扫描解析 | 卷组去重、当前根快照、同名系统、锁定、未挂载、字段缺失和空列表 |
| 身份检查 | 操作前目标断开或身份变化时拒绝写入；不用旧路径替代稳定身份 |
| 认证与执行 | 设置前取消不写入；错误、超时和结果未知不自动重启或重试 |
| 命令约束 | 每条启动写入路径带一次性语义；目标含空格或特殊字符不被 shell 解释 |
| 操作互斥 | 重复点击、重复实例不会同时触发切换 |
| 重启请求 | 仅工具成功才调用；失败或取消不声称已清除临时选择 |
| 安全数据 | 测试日志、错误报告和构建产物不含密码或未经脱敏的设备样例 |

不要编写只复述实现或为凑覆盖率的测试；完成有意义的局部验证后不无故扩大范围。
